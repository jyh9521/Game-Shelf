# GameShelf 0.1.8 — SteamGridDB 封面与平台管理

镜像：**`jyh9521/gameshelf:0.1.8`**（Linux/amd64），见 [Docker Hub](https://hub.docker.com/r/jyh9521/gameshelf/tags)。

## 更新内容

- 接受 SteamGridDB 两个官方图片域名，修复《时之笛》等条目选中后没有封面候选的问题。选中作品后显示选图区域；替换锁定封面须确认，保存后生效。
- 平台管理可新增、编辑名称与代号（如 `N64`）、删除未使用的平台。编辑代号保留发行、Edition 和拥有记录；仍有拥有记录引用的平台须先调整对应的发行平台。
- 从 0.1.7 升级没有新增 SQLite 迁移，备份格式仍为 v3；[资料服务变量](../METADATA.md)无需改名。

## Unraid 更新

1. 停止旧容器，保留整个 appdata 的一致性副本与容器配置。
2. 编辑现有容器，将 Repository 改为 **`jyh9521/gameshelf:0.1.8`**。保留原 `/data` 挂载、端口、PUID/PGID、代理和已配置的 API 变量。
3. 启动后检查页头为 `v0.1.8`、旧账号和游戏库正常。可用《时之笛》复测 SteamGridDB，并在平台管理修改 Nintendo 64 的代号。

回退时停止新容器，将升级前快照与原配置配套还原，再使用 `jyh9521/gameshelf:0.1.7`（`sha256:4c34d42cb052d0322a940086e45ad8552991ac409dc7ac833b115644076423d5`）。

## 复测

```sh
npm run build
npm run test:cover-platforms
docker pull jyh9521/gameshelf:0.1.7
docker pull jyh9521/gameshelf:0.1.8
npm run test:release
```

容器测试使用固定摘要的 0.1.7 和独立测试卷；SteamGridDB 用合成响应复现 CDN 地址，不使用真实 API 密钥或 Unraid 数据。
