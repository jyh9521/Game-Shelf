# GameShelf 0.1.10 — Steam 预览与 Gemini 简介翻译

## 更新内容

- 管理员可以按 SteamID64 **只读预览**可见游戏、AppID 和累计时长，不绑定账号或导入游戏。设置可选变量 `STEAM_WEB_API_KEY`；详见 [Steam 预览](../STEAM_PREVIEW.md)。
- 管理员可在游戏编辑器中用 Gemini **翻译简介**，支持简体中文、日语、英语。先预览，再采用；只有保存游戏才写入。设置可选变量 `GEMINI_API_KEY`；模型可选，详见 [Gemini 翻译](../GEMINI_TRANSLATION.md)。
- 保留原来的资料服务、SteamGridDB 封面翻页与现有变量。不新增数据库迁移，JSON 备份仍为 v3。

## Docker / Unraid 更新

1. 停止旧容器，备份 appdata 和容器配置。
2. 将镜像切换到 **`jyh9521/gameshelf:0.1.10`**（Linux/amd64）。保留原 `/data` 映射、端口、PUID/PGID、代理设置及现有 API 变量。
3. 按需新增 `GEMINI_API_KEY` 和/或 `STEAM_WEB_API_KEY`，重建容器。确认页头为 v0.1.10，检查原库与资料搜索。未配置新变量时核心功能照常。

需要回退时，用原配置和升级前 appdata 快照启动 [0.1.9](0.1.9.md)：`jyh9521/gameshelf@sha256:36ca594e074dcce83726de7d566683e38bd4710179619e0278632c4c3047597b`。

## 复测

在安装 Docker 和依赖、已构建本版本镜像的环境运行 `npm run test:release`。使用独立 Docker QA 卷和合成上游响应，不读取个人库或真实 API 凭据。真实 Steam、Gemini、其他资料服务凭据和 Unraid 设备另行验收。
