## Docker / Unraid 升级

1. 停止旧容器，保留升级前 appdata 一致性快照和容器配置。
2. 使用 `jyh9521/gameshelf:0.1.12`（Linux/amd64），保留 `/data`、端口、UID/GID、代理和 API 变量。
3. 连接 Steam 时设置 `APP_URL` 为实际访问站点的根地址，并设置 `STEAM_WEB_API_KEY`；HTTPS 同时设置 `SECURE_COOKIE=true`。
4. 重建后确认 v0.1.12、原游戏库和备份导出；按需完成 Steam 账号验证。Unraid 实际更新由部署者执行。

回退必须恢复升级前数据库与配置快照，再启动旧固定镜像：

```sh
docker pull jyh9521/gameshelf@sha256:728d8a9f0d7307c11276f48d0290611a2fec8a471af4051c5121f88bffe5d35a
```

该摘要对应 0.1.11。仅降级镜像不会撤销新增表或导入写入，v4 JSON 也不是旧版的恢复输入。
