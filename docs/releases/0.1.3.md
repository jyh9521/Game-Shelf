# GameShelf 0.1.3 — 2026-10-20

已发布：`jyh9521/gameshelf:0.1.3` 与 `latest`，linux/amd64。远程摘要：`sha256:d8584856d8159be0e0cf8e5ffb0bb2f7b2dffbe81e8d1d28ccc7338c4bcd71cf`；旧版 0.1.2 标签保留。12 项单元测试及真实 Docker 容器 30 次 HTTP 检查、桌面/手机操作、升级/重建持久化和独立快照回退通过。

## 变更

- 新增个人评分直接选择：全部评分、未评分、1～5 星。
- 可以与状态、收藏、平台和拥有记录条件组合；切换条件回到第一页，重置时清除评分条件。
- 页面显示版本更新为 v0.1.3。数据库迁移及 JSON schema_version=1 均无变化。

## Unraid 更新与人工验收

1. 在“备份与恢复”导出 JSON。停止容器后，另行备份原 appdata 数据目录（包括数据库及可能存在的 WAL/SHM 文件、setup-token 和其他设置）。
2. 编辑现有 GameShelf 容器，将 Repository 改成 `jyh9521/gameshelf:0.1.3`，应用并拉取新版镜像。
3. 保留原 `/data` 挂载、宿主端口、PUID、PGID、APP_URL 和 SECURE_COOKIE；不要重新创建空的数据目录。容器内端口仍为 3000。
4. 用原来的 NAS 地址和宿主端口访问。确认右上角显示 v0.1.3；如页面缓存未更新，强制刷新。
5. 验证原账号、游戏、拥有记录、评分、备注和时长仍在；升级不应要求重新初始化管理员。
6. 分别选择未评分、已有星级，再组合状态／收藏筛选；确认结果正确。重置应恢复完整游戏库。
7. 用手机操作评分按钮，确认无横向溢出；重启容器后检查记录仍保留。导出一次 JSON，确认原评分和记录可见。

真实 Unraid 运行结果由本轮人工验收确认；本地 Docker 测试不代替该项。

## 回退

停止 0.1.3，Repository 改回 `jyh9521/gameshelf:0.1.2`。如需恢复升级前的完整状态，应在容器停止时还原升级前匹配的 appdata 备份，再启动旧镜像。保留升级后的另一份数据副本，避免丢失验收期间新增内容。本版未新增迁移，但镜像回退本身不等于数据回退。
