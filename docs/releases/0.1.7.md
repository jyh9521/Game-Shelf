# GameShelf 0.1.7 — 游戏资料、封面与字段历史

镜像：**`jyh9521/gameshelf:0.1.7`**（Linux/amd64），见 [Docker Hub](https://hub.docker.com/r/jyh9521/gameshelf/tags)。

## 更新内容

- 用 Docker / Unraid 变量分别启用 IGDB、RAWG、TheGamesDB、ScreenScraper 游戏资料；SteamGridDB 仅提供竖版封面。搜索和预览不写库，保存时才接受候选。
- 游戏详情增加字段来源、原始候选、手动锁定与解除锁定。已锁定值（包括主动清空）不会被覆盖；无候选时解除锁定不改当前值。
- SQLite 启动时应用加法迁移 `20261109000000_metadata_history`，旧作品、拥有记录、关系、个人资料和会话保留。JSON 导出为 v3，支持 v1/v2 迁移和恢复。

## Unraid：从 0.1.6 升级

1. 先导出 JSON，停止旧容器，保存**整个原 appdata 的一致性副本**和容器配置。
2. 编辑现有容器，将 Repository 改成 **`jyh9521/gameshelf:0.1.7`**；保留原 `/data` 挂载、端口、PUID/PGID、访问地址和 Cookie 配置。
3. 需要哪个外部服务，就添加对应的 Docker **Variable**。见[变量、配对规则与获取方式](../METADATA.md)。没配置的服务保持关闭；修改变量后重新创建容器即可生效。
4. 启动后检查页头版本、旧登录和游戏库。打开「编辑资料 → 查找外部资料或封面」核对服务，再用一款测试作品确认搜索、预览与保存。重建容器后确认新增数据仍在。

## 回退

停止 0.1.7；配套恢复升级前 appdata 快照、原配置以及 `jyh9521/gameshelf:0.1.6`（`sha256:9148dbe5e4b81e996ee10b69f7c23ae7b21c723b9114accf5e678859a3af87e1`）。单独改回旧标签不会撤销数据库迁移；0.1.6 不读 v3。0.1.7 新写入的资料可先另存 v3 备份供新版本恢复。
