# GameShelf 0.1.9 — SteamGridDB 封面翻页

镜像：**`jyh9521/gameshelf:0.1.9`**（Linux/amd64），见 [Docker Hub](https://hub.docker.com/r/jyh9521/gameshelf/tags?name=0.1.9)。

## 更新内容

- 选中 SteamGridDB 作品后，可逐页浏览所有可导入的竖版封面，每页最多 12 张。部分图片被过滤或当前页没有可导入图片时，仍可继续翻页。
- 确认选中封面后自动收起查找面板；重新打开仍在原页。取消替换已锁定封面时保持展开。选择只暂存，点「保存游戏」才生效。
- 从 0.1.8 升级不新增数据库迁移；备份仍为 v3，现有 [Docker API 变量](../METADATA.md) 不变。

## Unraid 更新

1. 停止旧容器，备份现有 appdata 和容器配置。
2. 将 Repository 改为 **`jyh9521/gameshelf:0.1.9`**；如果使用 `latest`，直接更新。保留 `/data` 映射、端口、PUID/PGID 和 API 变量。
3. 启动后检查页头为 `v0.1.9`，确认旧游戏库仍在。搜索有多页封面的作品，翻到下一页选图并保存。

如需回退，停止新容器，用升级前 appdata 快照和原配置启动旧镜像 `jyh9521/gameshelf:0.1.8`（`sha256:f01b97270fba2d239b18f5fb2418db09c88942aeef35d3d5c28cafcf25e83022`）。

## 复测

```sh
npm run build
npm run test:cover-pagination
docker pull jyh9521/gameshelf:0.1.8
docker pull jyh9521/gameshelf:0.1.9
npm run test:release
```

测试使用独立 Docker QA 卷和合成 SteamGridDB 数据，不读取个人数据库或实际 API 凭据。
