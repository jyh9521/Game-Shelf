# GameShelf 0.1.11 — Steam 本地库候选对照

2026-11-17 开发版本。发布摘要与验证结果在完成远程拉取后补记。

## 更新内容

- Steam 预览对照本人完整本地库的标题、原名和本地化标题，显示单候选、多候选、未找到候选及缺少标题；支持搜索、组合筛选、分页和详情跳转。
- 单个作品不会因多个别名重复计数。相同名称仍为待确认候选，不表示 AppID 已关联或已拥有 Steam 版本；缺少名称时不匹配 AppID 占位符。候选列表最多显示 5 项，并显示完整数量。
- 采用个人有效资料及本人拥有平台，隔离其他用户；支持旧档案。修改本地资料后清空旧对照。只读预览不保存 SteamID64、游戏清单或时长，不合并游戏、不改评分和锁定字段。
- Next.js 从 16.4.3 固定升级为 16.4.6，处理 [GHSA-mfr8-8qww-v76h](https://github.com/vercel/next.js/security/advisories/GHSA-mfr8-8qww-v76h) 对应的受影响依赖。本项目没有使用公告描述的 `use cache` / `unstable_cache` 组合，不将依赖命中等同于已发生数据泄漏。
- 数据库无新增迁移，JSON 备份保持 v3；现有资料服务、Gemini 翻译及环境变量保留。

操作与边界见 [Steam 预览](../STEAM_PREVIEW.md)。账号归属确认、稳定 AppID 关联、确认导入和幂等同步仍为后续开发。

## Docker / Unraid 更新

1. 停止旧容器，备份 appdata 及配置。
2. 使用 `jyh9521/gameshelf:0.1.11`（Linux/amd64），保留 `/data` 挂载、端口、PUID/PGID、反向代理及全部 API 变量。
3. 按需启用 `STEAM_WEB_API_KEY`，重建后确认页头 v0.1.11 和原有游戏库；打开 Steam 预览检查候选对照。未设置密钥时手动库继续运行。

Unraid 实际更新由部署者执行。需要回退时，使用原配置及升级前 appdata 快照启动 0.1.10：

```sh
docker pull jyh9521/gameshelf@sha256:c8ae6df1a86cffaefaecdb6d6c191152a92fb7eb302fd0740d8df32ed4985ece
```

- 独立升级前快照回退到实际 0.1.10 镜像，原 v3 数据和会话恢复。测试容器与卷已清理。
